# Contributing

This is a small, opinionated project maintained by one person. Issues and
focused pull requests are welcome; large rewrites usually are not.

## Before you start

- Open an issue describing the problem before writing code.
- Keep a pull request to one concern.
- Run the tests that exist (see the README) and keep them green.
